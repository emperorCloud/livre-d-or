# Polices du PDF (facultatif mais recommandé)

Déposez ici ces 4 fichiers (téléchargeables gratuitement sur Google Fonts, licence OFL) :

- `CormorantGaramond-Regular.ttf`
- `CormorantGaramond-Italic.ttf`
- `CormorantGaramond-Bold.ttf`
- `Cinzel-Bold.ttf`

S'ils sont tous présents, le PDF les embarque (rendu élégant). S'il en manque un, le PDF utilise Times,
sans erreur. Les noms doivent être exacts.
